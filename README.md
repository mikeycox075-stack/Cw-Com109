COM109 Coursework Website
 
This repository contains my teams COM109 coursework project, a fitness and gym website developed using HTML, CSS, JavaScript, and jQuery.
 
The aim of this project was to design and develop a responsive and user friendly website that demonstrates our front end web development skills.
 
The website provides users with information about memberships, gym facilities, opening times, team members, and an online store while maintaining a consistent visual identity throughout the project.
